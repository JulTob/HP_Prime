# TEOREMAS

Visor de 28 resultados de los temas 1 y 2 de Optimización Continua, escrito en HP PPL. La fuente incluye definiciones, enunciados y pasos de demostración.

Ejecuta `TEOREMAS` desde el catálogo de programas para abrir el índice. También puedes elegir directamente una función exportada, como `T2CARATH`, `T2PROYEC`, `T2FARKAS` o `T2SYLVES`.

Cada visor comienza con la pantalla en blanco. Pulsa `1` para avanzar un paso. Cualquier otra tecla sale; al terminar aparece `fin`.

Conserva la codificación UTF-8 al pegar en Connectivity Kit. Este archivo es una fuente de programa, no un backup completo. Las pruebas previas y el alcance de la comprobación actual están en [VERIFICACION.md](../../docs/VERIFICACION.md).
