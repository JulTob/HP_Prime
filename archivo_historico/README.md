# Archivo histórico

`optimizacion_general/` conserva la primera guía general de optimización y su fuente editable. Su alcance es más amplio que el de las guías de temas 1 y 2.

Se guarda para recuperar material de otros temas. No es la versión recomendada para preparar exclusivamente el tema 2 ni incorpora todas las precisiones posteriores. Los archivos se han copiado sin modificar.

Los PDF de estudio actuales están en `apuntes/pdf/`.
